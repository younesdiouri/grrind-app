# Héros par défaut — sprites provisoires (#187)

Trois PNG RGBA de 1024 × 1024 pixels, vus de **trois-quarts dos** : le héros tient le bas de la
scène, tourné vers le mob qui la domine en face. Sol des pixels opaques vers 930, comme Al-Kasal.

**Provisoires.** Ce sont des silhouettes tracées en CoreGraphics (capuche, cape, lame, liseré
cyan de la palette) pour brancher la mise en scène avant les illustrations. Les livrables
définitifs suivent le pipeline des mobs (`../../enemies/al-kasal/README.md`) : pose de repos
générée et validée par l'utilisateur, attaque et coup reçu générés en référence de celle-ci, même
cadrage, même ligne de sol, mêmes noms de fichiers — le code ne change pas.
